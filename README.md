# VECTRA-86 MK-IV :: Interactive Retro OS Website

**Participant:** Chamalsha Liyanage  
**School:** Kingswood College  
**Competition Category:** WebWave  

## Overview
VECTRA-86 is not a standard website; it is a browser-based of a fictional 1986 industrial vector workstation. Avoiding the standard "Windows 95" visual clones, this project relies entirely on mathematical vector rendering, pure CSS3 hardware styling, and the Web Audio API to create a heavy, tactile, and highly interactive retro operating system. 

**Zero external libraries or frameworks were used.** Every pixel, scanline, and sound effect is generated procedurally using vanilla code.

## Core Hardware Modules

* **`[01] VECTOR.OSC`**: A real-time Lissajous oscilloscope and 3D wireframe radar engine rendering mathematics directly to an HTML5 Canvas.
* **`[02] SYNTH.SEQ`**: An 8-step chiptune matrix loop station powered by custom Web Audio API oscillators.
* **`[05] ASTEROID.VEC`**: A fully playable 1979-style vector arcade co-processor with rotational inertia physics and fracturing polygons.
* **`[06] SATLINK.3D`**: An orbital telemetry tracker rendering a rotating 3D wireframe globe.
* **`[07] MODEM.BBS`**: A simulated 2400-baud acoustic dial-up modem featuring authentic synchronous DTMF handshake tones and an interactive ASCII vault.
* **`[08] VOX.SAM`**: A 1984 Formant Speech Synthesizer combining native TTS with synchronous 8-bit frequency filtering and live jaw-animation mapping.

## Technical Highlights
* **Web Audio API:** Procedural generation of floppy drive stepper motors, CRT power-downs, degaussing electromagnetic hums, and 56K modem handshakes without using external `.mp3` or `.wav` files.
* **Advanced CSS3:** Multi-layered P1/P3 Phosphor bloom, chromatic glass glare, curved vignette shadows, and drifting CRT scanlines.
* **Dynamic DOM Management:** Custom draggable window manager with Z-index layering, tiling shortcuts, and interactive hot-swap microfloppy disks.

## Execution Instructions
For the optimal review experience:
1. Open the live deployment link.
2. Press **F11** to engage Full Screen mode.
3. Ensure audio is enabled and unmuted to experience the procedural sound design.
4. Click `[SPEAK TO JUDGES]` on the top navigation bar to initialize the VOX.SAM presentation.
